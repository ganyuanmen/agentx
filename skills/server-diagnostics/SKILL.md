# 服务诊断

## 适用条件
用户说某个本地服务不可用、启动失败或响应异常。

## 步骤
1. 确认进程是否在跑（exec 中用 ps / ss 等只读命令）。
2. 看最近的日志，先找第一条 fatal/error，而不是最后一条。
3. 确认端口占用与配置中声明的是否一致。
4. 复现一次最小请求，拿到真实返回体再下结论。

## 约束
- 只读诊断优先；需要重启或改配置时先向用户说明影响。
- 不把环境变量整体打印出来。
